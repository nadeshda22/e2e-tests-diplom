
# 🧪 E2E тесты для ИС «Учебный план»

Комплекс автоматизированных end-to-end тестов для веб-приложения «Информационная система «Учебный план»».  
Разработано в рамках дипломного проекта.

**Цель:** обеспечить регрессионное тестирование редактора учебных планов после внесения изменений в код.

---

## 📦 Установка

```bash
# Клонировать репозиторий
git clone <repository-url>

# Установить зависимости
npm install
```

## ✅ 01: «Открытие главной страницы»

Этот сценарий является **smoke-тестом** — проверяет, что приложение запущено и доступно.

### Что проверяет сценарий

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть URL `http://localhost:3001/38/` | Страница загружается без ошибок |
| 2 | Проверить заголовок страницы | Заголовок содержит `"?"` |

### Файлы сценария

**`features/01_smoke.feature`**

```gherkin
#language: ru
Функция: Проверка доступности приложения

  @smoke
  Сценарий: Открытие главной страницы
    Дано приложение открыто по адресу "http://localhost:3001/38/"
    Когда я открываю главную страницу
    Тогда заголовок страницы содержит "?"
```

### Запуск теста

```bash
npx nightwatch --tags @smoke
```

## 📥 02: «Импорт JSON-файла»

Этот сценарий проверяет, что приложение может корректно загрузить учебный план из JSON-файла.

### Что проверяет сценарий

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть главную страницу | Страница загружена |
| 2 | Нажать кнопку «Импорт» | Открывается меню, выбран пункт «Импорт» |
| 3 | Загрузить файл | Файл успешно загружается |
| 4 | Проверить номер специальности | Отображается номер `7-06-0114-01 ППм` |

### Файлы сценария

**`features/02_import.feature`**

```gherkin
#language: ru
Функция: Импорт учебного плана из JSON

  @import @smoke
  Сценарий: Успешный импорт корректного JSON-файла
    Дано приложение открыто по адресу "http://localhost:3001/38/"
    Когда я нажимаю кнопку импорта
    И я загружаю файл "test_data/up-20260305130554.json"
    Тогда отображается номер специальности
```

### Запуск теста

```bash
npx nightwatch --tags @import
```

## 📤 03: «Экспорт PDF»

Проверяет возможность скачивания PDF-файла после импорта данных и его соответствие эталону.

### Что проверяет сценарий

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Импортировать JSON-файл | Данные загружены |
| 2 | Открыть просмотрщик PDF | Отображается iframe с PDF |
| 3 | Скачать PDF | Файл сохраняется в папку download |
| 4 | Сравнить с эталоном | Файл соответствует ожидаемому |

**Файл сценария `features/03_export.feature`:**

```gherkin
#language: ru
Функция: Экспорт учебного плана в PDF

  @export @critical
  Сценарий: Экспорт PDF после импорта данных
    Дано приложение открыто по адресу "http://localhost:3001/38/"
    Когда я нажимаю кнопку импорта
    И я загружаю файл "test_data/up-20260305130554.json"
    Тогда отображается номер специальности
    Когда я открываю просмотрщик PDF
    И я скачиваю PDF из просмотрщика
    Тогда скачанный PDF в папке "test_data/download" совпадает с эталоном "expected_result_pdf.pdf"
```

### Запуск теста

```bash
npx nightwatch --tags @export
```

## 🌳 04: «Развёртывание дерева дисциплин»

Проверяет, что после импорта можно развернуть дерево и отображаются все разделы.

### Что проверяет сценарий

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Импортировать JSON-файл | Данные загружены |
| 2 | Нажать кнопку «Развернуть дерево элементов» | Дерево раскрывается |
| 3 | Проверить количество элементов | Найдено не менее 10 элементов |

**Файл сценария `features/04_expand_tree.feature`:**

```gherkin
#language: ru
Функция: Навигация по дереву учебного плана

  @tree @smoke
  Сценарий: 04.01 Развёртывание дерева после импорта
    Дано приложение открыто по адресу "http://localhost:3001/38/"
    Когда я нажимаю кнопку импорта
    И я загружаю файл "test_data/up-20260305130554.json"
    Тогда отображается номер специальности
    Когда я нажимаю кнопку "Развернуть дерево элементов"
    Тогда дерево дисциплин содержит не менее 10 элементов
```

### Запуск теста

```bash
npx nightwatch --tags @tree
```

## ✏️ 05: «Редактирование дисциплин»

Комплексный сценарий, проверяющий полный цикл работы с дисциплиной: добавление, редактирование, валидацию полей и удаление.

### Что проверяет сценарий

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Импортировать JSON-файл | Данные загружены |
| 2 | Добавить новую дисциплину | Открывается диалог добавления |
| 3 | Выбрать дисциплину из справочника | Дисциплина выбрана |
| 4 | Выбрать раздел «Факультативные дисциплины» | Раздел выбран |
| 5 | Развернуть дерево | Дисциплина отображается |
| 6 | Открыть редактирование | Открывается форма редактирования |
| 7 | Установить часы (позитивные и негативные сценарии) | Валидация работает корректно |
| 8 | Сохранить изменения | Данные сохранены |
| 9 | Удалить дисциплину | Дисциплина исчезает из дерева |

**Файл сценария `features/05_disciplines.feature`:**

```gherkin
#language: ru
Функция: Полный цикл работы с дисциплиной

  Предыстория:
    Дано приложение открыто по адресу "http://localhost:3001/38/"
    Когда я открываю главную страницу
    Тогда заголовок страницы содержит "?"
    Когда я нажимаю кнопку импорта
    И я загружаю файл "test_data/up-20260305130554.json"
    Тогда отображается номер специальности
    Когда я нажимаю кнопку добавления элемента плана
    И я выбираю дисциплину с названием "Инновации в высшем образовании..."
    И я выбираю раздел "Факультативные дисциплины"
    И я нажимаю кнопку "Развернуть дерево элементов"
    Тогда дисциплина отображается в дереве

  @disciplines @full
  Структура сценария: Валидация часов для Семестра I
    Когда я открываю редактирование этой дисциплины
    И я устанавливаю часы "Лекции" в семестре "1" в "<часы>"
    И я сохраняю изменения
    И я открываю редактирование этой дисциплины
    Тогда поле часов "Лекции" в семестре "1" должно содержать "<ожидаемый_результат>"

    Примеры:
      | часы | ожидаемый_результат |
      | 12   | 12                  |
      | abc  |                     |
      | 0    |                     |
      | -5   | 5                   |
```

### Запуск теста

```bash
npx nightwatch --tags @disciplines
```

## 🚀 Запуск тестов

### Команды

```bash
# Все тесты
npx nightwatch

# По тегам
npx nightwatch --tags @smoke        # Только smoke-тесты
npx nightwatch --tags @import       # Только импорт
npx nightwatch --tags @export       # Только экспорт PDF
npx nightwatch --tags @tree         # Только дерево дисциплин
npx nightwatch --tags @disciplines  # Только редактирование

# Несколько тегов
npx nightwatch --tags "@smoke @import"
npx nightwatch --tags "not @ignore"
```

## 📸 Скриншоты

Система автоматически создаёт скриншоты на каждый ключевой шаг теста.

**Особенности:**
- Дедупликация — каждый скриншот создаётся только один раз
- Поддержка кириллицы — имена файлов на русском языке
- Автоматические скриншоты при падении теста

**Примеры имён файлов:**
```
specialty_number_found.png
title_verified.png
import_menu_clicked.png
file_imported_successfully.png
hours_set_i_лекции_12.png
tree_contains_23_elements.png
```
