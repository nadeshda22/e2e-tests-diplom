
# 🧪 E2E тесты для ИС «Учебный план»

Комплекс автоматизированных end-to-end тестов для веб-приложения «Информационная система «Учебный план»».  
Разработано в рамках дипломного проекта.

**Цель:** обеспечить регрессионное тестирование редактора учебных планов после внесения изменений в код.

## 📦 Установка

```bash
# Клонировать репозиторий
git clone <repository-url>

# Установить зависимости
npm install
```

---

## ✅ Первый сценарий: «Открытие главной страницы»

Этот сценарий является **smoke-тестом** — проверяет, что приложение запущено и доступно.

### Что проверяет сценарий

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть URL `http://localhost:3001/38/` | Страница загружается без ошибок |
| 2 | Проверить заголовок страницы | Заголовок содержит `"?"` |

### Файлы сценария

**`features/01_smoke.feature`**

```gherkin
#language: ru
Функция: Проверка доступности приложения

  @smoke
  Сценарий: Открытие главной страницы
    Дано приложение открыто по адресу "http://localhost:3001/38/"
    Когда я открываю главную страницу
    Тогда заголовок страницы содержит "?"
```

## 📥 Второй сценарий: «Импорт JSON-файла»

Этот сценарий проверяет, что приложение может корректно загрузить учебный план из JSON-файла.

### Что проверяет сценарий

| Шаг | Действие | Ожидаемый результат |
|-----|----------|---------------------|
| 1 | Открыть главную страницу | Страница загружена |
| 2 | Нажать кнопку «Импорт» | Открывается меню, выбран пункт «Импорт» |
| 3 | Загрузить файл | Файл успешно загружается |
| 4 | Проверить номер специальности | Отображается номер `7-06-0114-01 ППм` |

### Файлы сценария

**`features/02_import.feature`**

```gherkin
#language: ru
Функция: Импорт учебного плана из JSON

  @import @critical
  Сценарий: Успешный импорт корректного JSON-файла
    Дано приложение открыто по адресу "http://localhost:3001/38/"
    Когда я нажимаю кнопку импорта
    И я загружаю файл "test_data/up-20260305130554.json"
    Тогда отображается номер специальности
```

## 🚀 Запуск тестов

### Команды

```bash
# Все тесты
npx nightwatch

# Только smoke-тесты
npx nightwatch --tag smoke

# Только тесты импорта
npx nightwatch --tag import

# С подробным выводом
npx nightwatch --verbose
```
